================================================================================
 GlobalConditional - University Cluster Setup Instructions
================================================================================

PREREQUISITES
  - SSH access to the cluster
  - The repo copied/cloned to your home directory

--------------------------------------------------------------------------------
1. SSH into the cluster
--------------------------------------------------------------------------------

  ssh youruser@cluster.university.edu

--------------------------------------------------------------------------------
2. Clone the repo
--------------------------------------------------------------------------------

  git clone <your-repo-url> ~/GlobalConditional
  cd ~/GlobalConditional

--------------------------------------------------------------------------------
3. Load cluster modules
--------------------------------------------------------------------------------

  Check what is available:

    module avail python
    module avail cuda
    nvidia-smi                   # check CUDA version on GPU nodes

  Load Python and CUDA (exact names vary by cluster):

    module load python/3.10
    module load cuda/12.1

--------------------------------------------------------------------------------
4. Create a virtual environment
--------------------------------------------------------------------------------

  python3 -m venv CDM_venv
  source CDM_venv/bin/activate

  Verify:

    which python                 # should point to CDM_venv/bin/python
    which pip                    # should point to CDM_venv/bin/pip

--------------------------------------------------------------------------------
5. Install dependencies
--------------------------------------------------------------------------------

  If your cluster CUDA version matches the default PyTorch build:

    pip install torch numpy scipy tqdm flow-matching torchdiffeq POT scikit-learn matplotlib pandas

  If GPU is not detected after this, install PyTorch with explicit CUDA version
  (replace cu121 with your cluster's version, e.g. cu118, cu124):

    pip install torch --index-url https://download.pytorch.org/whl/cu121

  Verify GPU works:

    python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"

--------------------------------------------------------------------------------
6. Quick test (interactive / login node, CPU only)
--------------------------------------------------------------------------------

  cd ~/GlobalConditional
  source CDM_venv/bin/activate
  python scripts/run_experiment.py --device cpu --epochs 1 --n-attempts 1

  This should complete in under a minute and confirm everything works.

--------------------------------------------------------------------------------
7. Submit a GPU job via SLURM
--------------------------------------------------------------------------------

  Save the following as job.sh in ~/GlobalConditional:

  ---- cut here ----
  #!/bin/bash
  #SBATCH --job-name=globalcond
  #SBATCH --partition=gpu
  #SBATCH --gres=gpu:1
  #SBATCH --cpus-per-task=4
  #SBATCH --mem=16G
  #SBATCH --time=02:00:00
  #SBATCH --output=run_%j.log

  module load python/3.10
  module load cuda/12.1
  source /sci/labs/orzuk/orzuk/venvs/CDM_venv/bin/activate
  cd ~/GlobalConditional

  python scripts/run_experiment.py --device cuda --epochs 20 --n-attempts 25
  ---- cut here ----

  Submit:

    sbatch job.sh

  Monitor:

    squeue -u $USER              # check job status
    tail -f run_<jobid>.log      # watch output

  Cancel:

    scancel <jobid>

--------------------------------------------------------------------------------
8. If your cluster uses PBS instead of SLURM
--------------------------------------------------------------------------------

  Replace the SBATCH headers with:

  ---- cut here ----
  #!/bin/bash
  #PBS -N globalcond
  #PBS -q gpu
  #PBS -l select=1:ncpus=4:mem=16gb:ngpus=1
  #PBS -l walltime=02:00:00
  #PBS -o run.log
  #PBS -e run.err

  module load python/3.10
  module load cuda/12.1
  source /sci/labs/orzuk/orzuk/venvs/CDM_venv/bin/activate
  cd ~/GlobalConditional

  python scripts/run_experiment.py --device cuda --epochs 20 --n-attempts 25
  ---- cut here ----

  Submit with: qsub job.sh
  Monitor with: qstat -u $USER

--------------------------------------------------------------------------------
9. If your cluster prefers conda over venv
--------------------------------------------------------------------------------

  module load anaconda3          # or miniconda, name varies
  conda create -n GlobalConditional python=3.10 -y
  conda activate GlobalConditional
  pip install torch numpy scipy tqdm flow-matching torchdiffeq POT scikit-learn matplotlib pandas

  Then in job scripts, replace the venv activation line with:

    source activate GlobalConditional
    # or
    conda activate GlobalConditional

--------------------------------------------------------------------------------
10. Example runs with different configurations
--------------------------------------------------------------------------------

  Default (2D MoG, LGD-CM, quick):
    python scripts/run_experiment.py

  Full run:
    python scripts/run_experiment.py --epochs 20 --n-attempts 25

  Using D-FLOW instead:
    python scripts/run_experiment.py --method DFLOW

  Using plain LGD (diffusion conditional):
    python scripts/run_experiment.py --method LGD --architecture diffusion --epochs 20

  Using a params file:
    python scripts/run_experiment.py --params-file SimulationParameters/mog_2d_full.txt

  Random 10D MoG:
    python scripts/run_experiment.py --random-mog --dim 10 --n-components 4 --condition-on 1

  Reproducible run:
    python scripts/run_experiment.py --seed 42

  Compare likelihood vs D-FLOW (all-in-one):
    python scripts/compare_methods.py --n-attempts 5 --direct --architecture fm --epochs 10
